1

API 串接與鑑權

🔐

HMAC-SHA256 簽章

Coupang API 需要 HMAC 簽章認證。AI Agent 自己讀文件、寫簽章邏輯、debug 簽章路徑問題（必須包含完整 API path），最終成功串接。

coupang_api.py
🌐

多平台資料抓取

momo 用 JSON-LD 解析、蝦皮/PChome 用 Playwright 瀏覽器自動化。四個平台，三種抓取策略，AI Agent 自動選擇最佳方案。

coupang_compare.py
2

自動化排程（Zero Token）

⏰

Cron Job 管理

AI Agent 幫忙建立、排程、除錯所有 cron jobs。排程用 no_agent=True 模式，純腳本執行零 token 消耗。

no_agent=True → 零成本
🔄

失敗自動重試

資料抓取失敗時自動 retry，API rate limit 時自動退避。AI Agent 會設計容錯機制，不是只寫 happy path。

retry loop + exponential backoff
3

資料管線與分析

📊

歷史價格追蹤

每次掃描自動記錄價格，建立歷史資料庫。跌到歷史低點時自動觸發推播——AI Agent 會設計「什麼時候該通知人」。

price_history.json
⚖️

跨平台比價引擎

同一商品同時比 4 個平台，找最低價。AI Agent 不只做資料抓取，還做了「決策邏輯」——什麼時候該推、什麼時候該等。

coupang_compare.py
4

內容生成

✍️

Threads 文案自動生成

價格低點時自動生成 Simon 風格的 Threads 貼文：短句、生活場景、無驚嘆號、無 emoji。AI Agent 學習你的語氣，不是萬用模板。

generate_threads_post()

智能商品挖掘

掃描 25 個關鍵字，用分數系統篩選高價值商品。≥ 7 分自動追蹤——AI Agent 幫你做「什麼值得推」的判斷。

coupang_discover.py
